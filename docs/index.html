GitHub Secrets jo chahiye

Repo → Settings → Secrets and variables → Actions → New repository secret. Sirf wo platforms ke secrets dalein jo use karne hain.

PlatformSecrets
FacebookFACEBOOK_PAGE_ID FACEBOOK_PAGE_TOKEN
InstagramINSTAGRAM_USER_ID (token: INSTAGRAM_ACCESS_TOKEN, khali ho to Facebook wala use hota hai)
ThreadsTHREADS_USER_ID THREADS_ACCESS_TOKEN
PinterestPINTEREST_BOARD_ID PINTEREST_ACCESS_TOKEN (optional: PINTEREST_REFRESH_TOKEN PINTEREST_APP_ID PINTEREST_APP_SECRET PINTEREST_API_BASE)
OptionalGRAPH_API_VERSION (default v24.0)
